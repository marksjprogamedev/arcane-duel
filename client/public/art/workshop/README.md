# Wizard Workshop atlas

Upload `wizard_workshop_game_atlas.png` into this directory and rename it to **game-atlas.png**.

The Workshop in `client/index.html` expects `/art/workshop/wizard_workshop_game_atlas.png` (1368 × 2187 pixels). This atlas packs the 71 original transparent sprites without re-cropping them; the sprite rectangles are declared in the Workshop script. Until this PNG is uploaded, the Workshop intentionally displays its temporary SVG shapes instead of broken images.

The source package is `wizard_category_atlases_extra_spaced.zip`. Keep it for editing; the compact game atlas is for rendering only.
