# Art docs

Everything about how the game's art is made, so it stays consistent between people and over time.

- [`STYLE.md`](STYLE.md): the style rules (light, outline, shading, palette, sizes). Read before drawing anything.
- [`WORKFLOW.md`](WORKFLOW.md): tools, how to export, where files go, how to check and wire them in.
- [`ASSETS.md`](ASSETS.md): what exists, what is a placeholder, what is next.

Keep these up to date in the same commit as the art (like the other docs in `docs/`).
