# Mark's Future Work

Actionable bugs and feature requests to pick up later. These are tracked here so they remain
separate from the unapproved concepts in `FUTURE_IDEAS.md`.

## Open

- [ ] **Tempest Bolt performance:** Tempest Bolt can cause frame-rate drops, with input delay reaching about 600 ms. Investigate and fix the performance spike.
- [ ] **Sword aim:** Aim sword attacks in the direction of the cursor.
- [ ] **Trap persistence and disarming:** Address traps disappearing and add an option to disarm a trap.
- [ ] **Movement at corners:** Smooth movement around edges and corners; players can currently get stuck easily.
- [ ] **Shield fallback:** When no element is loaded, pressing Space should shield using the current attack style.
- [ ] **Multiplayer attack direction:** Fix the rendering glitch where an enemy's attack appears to come from behind the player even though it should be on screen.
- [ ] **Point-blank wall collision:** Fix projectiles that travel through walls when fired at point-blank range.
